# Irvine Rainfall by Month, 2019–2022

**Live:** https://mentalplatypus.github.io/Irvine-Rainfall-Data/

A line chart of monthly rainfall in Irvine, California, with one line per year, made with Python, pandas and matplotlib.

Data: [UC Cooperative Extension Orange County weather station](https://ceorange.ucanr.edu/about/weather/?weather=station&station=75)

Part of [David Wang's portfolio](https://mentalplatypus.github.io/).
